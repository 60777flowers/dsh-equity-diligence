## 1. 交付形态

- DSH 插件包：`dsh-equity-diligence`，纯 ESM、零运行时 npm 依赖。
- Host 半侧：`src/index.js` → `EquityService` → kernel / engines / builders。
- Client 半侧：`client.js`（`__ModuleLoader__` 纯 JS，不需要构建链）。
- 本地安装：profile `dependencies` + `cordis.patch.yml` 单行插入；已提供安装/回滚脚本。

## 3. 内核

- `registry`：加载 32 类 schema、25 个模块、5 个预设；模块 manifest 校验、semver range、双根（内置 + `~/.dsh/equity/modules`）。
- `artifacts`：分区目录、revision、current/verified/running/rejected、语义哈希、证据/claim 账本、lineage。
- `playbook`：类型→生产者索引、`onMissing block/degrade`、软引用不参与环、`all` 按方案内生产者展开、拓扑排序、order_violation、duplicate_producer、版本校验。
- `runner`：Unit 生成、输入 pin、fixture/private/native 执行器、门、issue、检查点、预算、暂停/取消/恢复、幂等跳过。
- `gates`：schema/coverage/rule/rubric/checklist；`rules/gates.json` 即使 manifest 未显式声明也会作为合成 rule 门执行；支持 30+ consistency kind（range/enum/unique/sum/crossFieldEqual/requiredWhen/setCovers/subset/refExists/forbiddenText/coverage/requiresLedger 等）。
- `stale`：R1 内容、R2 代码、R3 依赖集合（只报缺失）、R4 时效、R5 rejected upstream；不传播。
- `triggers`：T1–T12，只输出核查项/红旗，不阻断交付。
- `migrate`：旧 `01_平台收集` / `04_批量调研` / `05_交付` → draft 底稿，原文件不动，actor=import。

## 4. 执行器与来源链

- `SourceAcquisition`：每次查询隔离、失败不拖垮整单元；fetch 记录 status/finalUrl/truncated/rawHash；URL 只允许 http(s)，拒绝本机/内网；出网审计。
- PDF：`python/pdf_extract.py`（PyMuPDF 优先，pypdf 兜底），按页返回文本。
- `PrivateAgentExecutor`：`ctx.subagents.startActivation`（spawn，outputSchema，caller 交付），结果回源校验引文。**需要父 Agent**（`exec.agent`）；从工具调用时优先走它，UI/API 直连没有父 Agent，按设计回退 `native-loop`，不是失败。
- `NativeResearchExecutor`：JSON 动作协议，最多 `budget.toolCallsPerUnit` 步；每步一个动作；final 必须过 schema；失败/超步显式报错。
- `FixtureExecutor`：离线 golden，确定性。
- `CompositeExecutor`：`red-flags` 走确定性触发器；`deliverable` 走 Python 构建器；其余走 primary。

## 5. 交付

- `src/builders/package.js`：摘要、范围/口径、工作底稿、证据快照、cellMap、manifest、QA、签发记录。
- `python/build_workbooks.py`：02 综合工作簿 11 sheet；03 7+N（7 固定 + ≤3 家族 + 说明，清理版 20 列）；自定义蓝/灰样式、冻结、筛选、标绿。
- `python/inspect_workbook.py`：只读体检（sheet/表头/公式错误/空表头/重复表头/样例行）。
- `python/check_deliverable.py`：结构/列语义/六态/空值/公式/多路径/标绿一致性检查。
- `src/builders/check.js`：交付 QA（阻断项：缺摘要、material 无证据、摘要 claimId 悬空、stale/rejected、cellMap 未 pin、工作簿结构/表头/公式、导入底稿被 verified）。

## 8. 已知限制（诚实清单）

1. **模块内容为 draft**：除 `investment-map` 外的 24 个模块（`provenance.author: ai-draft`、`origin: agent`）方法论由 AI 初稿生成，未经金融专家逐模块评审；`policy.exposure` 尤其不能当法律意见。
2. **未做真实联网全量 smoke**：本次没有可用的付费库/完整公告批量抓取；`private-agent` 的真实子代理路径、PDF/OCR 需要真实 provider/凭据；fixture 只验证结构、门、交付链。
3. **native-loop 是兜底**：JSON 动作协议不是原生 tool-calling，长任务效率低于 private-agent；生产建议优先 private-agent。
4. **合规边界**：只做公开信息；不采集隐私；不替代现场尽调/法律/审计/税务/估值。
5. **UI 视觉验证**：已在同构 demo profile 验证 boot graph + API；当前 GUI 需刷新/重启，浏览器自动化不在本会话工具范围内，视觉像素级验收未做。
6. **R2 模块联调**：quick/standard/deep 已编译通过，但仅 skill-only 做了完整 golden 运行；R2 模块的跨模块对账/触发器阈值需真实项目校准。
7. **脚本能力**：模块 `scripts` / L2 未开放；自定义模块默认声明式；`wrap` 为后续。
8. **索引**：`~/.dsh/equity/projects.json` 是索引而非真相；删索引可由项目目录重建（当前实现按索引列出，重建命令为后续小项）。
