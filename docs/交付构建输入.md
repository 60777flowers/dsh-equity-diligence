# 交付构建输入契约（Python 构建器）

Python 构建器只做两件事：**把已确定的 JSON 画成 Excel**，以及**体检 Excel**。它不调用模型、不联网、不新增业务事实。

入口：

```bash
python python/build_workbooks.py --input <input.json> --out <05_交付目录>
python python/inspect_workbook.py --file <xlsx> --json <output.json>
```

构建器输出：

```
<out>/02_综合尽调工作簿.xlsx
<out>/03_专项_投资版图_7+N.xlsx
<out>/workbook_map.json          # 实际 sheet/表头/行数/列宽，供 QA
```

## 2. 综合工作簿（02）

固定 sheet 顺序：

1. `00_目录`
2. `01_执行摘要`
3. `02_主体与股权`
4. `03_业务与技术`
5. `04_财务`
6. `05_风险`
7. `06_待核清单`
8. `07_资料请求`
9. `08_来源索引`
10. `09_模块底稿索引`
11. `10_体检单`

- 每 sheet 第 1 行标题（合并 A1:N1），第 2 行表头，第 3 行起数据；冻结 A3 或 B3；自动筛选第 2 行；列宽按内容；自动换行。
- `00_目录`：章节、sheet、说明、数据截至日。
- `01_执行摘要`：`序号 / 事实 / 影响 / 证据强度 / materiality / 下一步 / claimId / artifactId`。
- `02`–`05`：来自 `comprehensive.sheets`；字段行格式 `字段 / 值 / 状态 / 证据`。
- `06_待核清单`：`主题 / 问题 / 为什么重要 / 优先级 / 来源`。
- `07_资料请求`：`编号 / 主题 / 问题 / 为什么 / 优先级 / 负责人 / 状态`。
- `08_来源索引`：`evidenceId / 标题 / URL / 来源类型 / 权威度 / 核验状态 / 截至日 / 抓取时间 / rawHash`。
- `09_模块底稿索引`：`artifactId / 类型 / 主体 / 分区 / 状态 / revision / contentHash / asOf / 证据数 / claim 数`。
- `10_体检单`：`检查项 / 结果 / 说明`。

## 3. 7+N 专项（03）

- 表格名严格：`1-直接投资`、`2-合作基金-GP`、`3-合作基金-主导LP`、`4-合作基金-财务LP`、`5-海外平台`、`6-合资公司`、`7-国内基地`、`8-<姓名>家族`、`9-<姓名>家族`、`10-<姓名>家族`、`说明`。
- 7 张固定表始终存在；家族表按 `sevenN.rows[].sheet` 中出现的 8/9/10 表生成，最多 3 张；没有则只生成 7 + 说明。
- 表头 24 列（顺序固定）：
  1 平台/主体
  2 类型/角色
  3 股权结构/出资
  4 战投定位/协同方向
  5 时间/备注
  6 公司名称
  7 调查时间
  8 审核状态
  9 最新融资轮次和情况
  10 第一大股东持股比例(%)
  11 前5大股东合计持股比例(%)
  12 股东数目
  13 创始团队是否实控
  14 创始团队背景
  15 产业链环节
  16 扩产周期
  17 产业景气度
  18 产品毛利率
  19 该公司行业排名(国际/国内)
  20 是否与委托方技术有关联、有合作潜力
  21 历史融资总额
  22 投资合作评估（重点字段）
  23 数据质量说明
  24 结果JSON文件
- 清理版删除第 7、8、23、24 列，其余列顺序不变（交付文件用清理版；仍保留 7+N 表结构）。
- 行 = 平台路径 × 被投实体；同一实体多路径在各表各一行，不跨表去重。
- 标绿：只对“合作潜力”与“投资合作评估”两列，规则：
  - 合作潜力正向：合作潜力：高 / 高潜力 / 合作潜力高 / 高关联 / 高关联度；排除：中-高、中高、中等偏高。
  - 投资合作评估正向：适合投资合作 / 适合投资/业务合作 / 适合投资/合作 / 适合投资与合作 / 适合业务协同 / 适合以业务协同 / 供应链导入型合作；排除：不适合投资合作（排除优先）。
  - 绿色 `C6EFCE`，只涂背景，不改文字。
- `说明` sheet：口径、待关注清单、数据来源、整理日期、标绿规则说明。
- 样式：海军蓝 `#1F4E79` 白字表头，浅蓝 `#D9E1F2` 列头，浅灰 `#F2F2F2` 分组行；细边框；首行冻结；自动筛选；数字右对齐；比例列显示 `42.50%`；金额列显示币种千分位；日期 `YYYY-MM-DD`；空值显示六态文案，不留空。

## 4. 体检（inspect_workbook.py）

输出 JSON：

```jsonc
{
  "ok": true,
  "file": "...",
  "sheets": [{ "name": "1-直接投资", "rows": 12, "cols": 20, "headers": ["..."], "freeze": "A2", "autoFilter": "A2:T12" }],
  "formulaErrors": [],
  "emptyHeaders": [],
  "duplicateHeaders": [],
  "sampleRows": [{ "sheet": "...", "row": 3, "values": ["..."] }]
}
```

- 检查公式错误 `#REF! / #N/A / #VALUE! / #DIV/0!`。
- 检查表头空/重复。
- 检查 7+N 表名与列数；`说明` 页存在。
- 只读，不修改文件。

## 5. 约束

- 只用标准库 + openpyxl；不依赖 pandas。
- 不联网、不调用模型、不写项目外路径。
- 输入 JSON 的字段缺失时，写“未提供/not_reviewed”，不得留空、不得编造。
- 输出文件原子写：先写临时文件，再替换。
- 所有中文用 UTF-8；`说明` 页必须包含“本报告基于公开信息，不构成投资建议”等免责声明。
