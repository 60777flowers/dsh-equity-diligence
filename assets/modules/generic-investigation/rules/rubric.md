# 审核 rubric · 通用调查（兜底）

> 五维各 1–5 分；**任一维 ≤2 分即不通过**。评分看 findings、markdown 与证据原文。
> 模块状态 `draft`：本 rubric 尚未经金融专家评审。

## 1. 事实准确性（结论与口径）

| 分 | 判据 |
|---|---|
| 5 | 结论数值、日期、主体与原文完全一致；口径（期间/币种/范围）随文标注；无因果推断当事实 |
| 4 | 基本一致，个别数字只到区间但注明来源 |
| 3 | 有 1–2 处表述概括但仍可回溯原文 |
| 2 | 出现原文未支持的数字或强因果表述 |
| 1 | 结论与来源矛盾，或凭空生成事实 |

## 2. 引用准确性（证据）

| 分 | 判据 |
|---|---|
| 5 | 每条结论有 `supports`，`quote` 为原文片段、`locator` 可回查；`material` 覆盖 100% |
| 4 | 主要结论有引文，个别为背景性描述且已标 C 级 |
| 3 | 有 1–2 条结论只有搜索摘要级证据 |
| 2 | 多条结论无证据，或引文无法命中 |
| 1 | 编造 URL/引文，或无任何证据 |

## 3. 完整性（拆题与深度）

| 分 | 判据 |
|---|---|
| 5 | 子问题 3–7 个且各自有结论或明确缺口；轮次/来源数/结论数达到 `depth` 下限；反证检索已做 |
| 4 | 子问题覆盖，轮次达标，个别缺口未写已尝试路径 |
| 3 | 缺 1 个子问题，或反证检索未做但已说明 |
| 2 | 只答表层问题，深度未达标 |
| 1 | 未拆题，直接给一段泛泛结论 |

## 4. 来源质量（source quality）

| 分 | 判据 |
|---|---|
| 5 | A/B 级为主并交叉；官网自述只作声明证据；无 D 级来源进入结论 |
| 4 | A+B 为主，个别结论依赖权威媒体 |
| 3 | 主要依赖官网与媒体，未回原始文书 |
| 2 | 多数结论来自自媒体或转载 |
| 1 | 依赖传闻，无可回查来源 |

## 5. 对账（consistency）

| 分 | 判据 |
|---|---|
| 5 | `markdown` 每段可对到 claim；`findings` 与 claims 一致；`not_disclosed_after_search` 均有 ledger；无投资建议 |
| 4 | 对账通过，个别段落引用不精确 |
| 3 | 有一处 markdown 表述超出 claim 范围但未新增数字 |
| 2 | markdown 出现 claims 之外的事实，或 `not_found` 无 ledger |
| 1 | 报告与 findings 互相矛盾 |

## 判定与记录

- 五维分数与扣分点写入底稿 `checks[]`，扣分点挂 `claimId`/`evidenceId`。
- 任一维 ≤2：退回补查或收敛结论。
- 3 分：可作为初筛结论，但须在报告标“初步、未穷尽”。
- 5 分：可并入交付摘要，无需二次核验。
- 本模块结论不构成投资建议；`deliverable` 引用时须保留此边界。
