# 审核 rubric · 报告与附表

> 五维各 1–5 分；**任一维 ≤2 分即不通过**。评分看交付包、`cellMap` 与底稿原文。
> 模块状态 `draft`：本 rubric 尚未经金融专家评审。

## 1. 事实准确性（不创造新事实）

| 分 | 判据 |
|---|---|
| 5 | 报告每个数字与底稿 claim 逐项一致；无新增主体、日期、金额；口径随文标注 |
| 4 | 基本一致，个别措辞压缩导致口径略模糊但可回溯 |
| 3 | 有 1–2 处数字改写为约数但保留 `claimId`，读者可回查 |
| 2 | 出现无底稿支撑的数字或结论 |
| 1 | 报告与底稿矛盾，或凭空补充事实 |

## 2. 引用准确性（血缘）

| 分 | 判据 |
|---|---|
| 5 | 摘要每条挂 `claimId`+`artifactId`；工作簿每个数字 pin `artifactId+revision+contentHash`；三跳抽查全通过 |
| 4 | 摘要齐全，工作簿个别单元格缺 revision |
| 3 | 摘要齐全，工作簿按区域 pin 而非按单元格 |
| 2 | 摘要缺 `claimId`，或工作簿无 `cellMap` |
| 1 | 无法追溯任何数字 |

## 3. 完整性（结构与内容）

| 分 | 判据 |
|---|---|
| 5 | 01–05 + manifest + QA 齐全；工作簿 11 页签；7+N 表数/表名/列序合规；家族表 ≤3；多路径无漏行 |
| 4 | 结构齐全，个别页签为空但已说明 |
| 3 | 缺一个非核心页签或一张家族表未建（群体不足 3 个时属正常） |
| 2 | 缺核心页签、7+N 表数不符、多路径实体漏行 |
| 1 | 只有摘要，没有工作簿与底稿包 |

## 4. 来源质量（source quality）

| 分 | 判据 |
|---|---|
| 5 | 摘要证据强度标注 A–D 与独立源数；关键结论引用 A 级来源；冲突在摘要可见 |
| 4 | 多数结论标证据强度，个别为 B 级 |
| 3 | 只标“高/中/低”，未区分来源级别 |
| 2 | 摘要不标证据强度，读者无法判断可信度 |
| 1 | 引用媒体或传闻作为唯一支撑 |

## 5. 对账（consistency）

| 分 | 判据 |
|---|---|
| 5 | QA 阻断 0；摘要与工作簿数字一致；共享指标跨页签一致；stale/rejected 已处理；`qa.passed` 与 `blocking` 一致 |
| 4 | 阻断 0，个别非阻断未在体检页说明 |
| 3 | 阻断 0，但存在 1 处同口径表述不一致（不影响数字） |
| 2 | 存在未处理 stale，或摘要与工作簿数字不一致 |
| 1 | QA 未跑或人为置 `passed=true` |

## 判定与记录

- 五维分数、扣分点、阻断项写入 `qa` 与体检页签，扣分点挂 `claimId`/`artifactId`。
- 任一维 ≤2：不得签发，退回修复。
- 3 分：可交付，但须在体检页与摘要标注局限。
- 5 分：可直接提交复核与签发。
- 阻断仅来自一致性/结构/血缘；红旗多少不构成阻断。
