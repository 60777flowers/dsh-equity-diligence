# 审核 rubric · 客户、订单与招投标（customers-orders）

> 模块状态：**draft**，未经过金融专家评审。
> 评分对象：单个 `valuechain.parties` 底稿。五维各 1–5 分，**任一维 ≤2 即整体不通过**。

## 1. 五维评分表

| 维度 | 1 分 | 2 分 | 3 分（及格线） | 4 分 | 5 分 |
|---|---|---|---|---|---|
| **事实准确性** | 客户名、占比、订单金额与来源不符 | 集中度缺分母或期间，名称多为推测 | 主要客户与 c1/c5 与披露一致，分母与期间已标注 | 客户名称可核到工商/代码，订单与中标有原文 | 全部客户可核（或明确标注脱敏），金额含税口径、合并规则、期间全部对上原文 |
| **引用准确性** | 引文不存在 | 引文为改写，locator 缺失 | 引文为原文片段，到章节/段落 | 每条 material claim 有 supports | 关键集中度数字有双源交叉（招股书+年报），独立源已核 |
| **完整性** | 只有客户名 | 缺集中度或订单其一 | 客户、集中度、订单/中标三块齐备 | 客户 + 集中度 + 认证阶段 + 订单 + 中标全部覆盖 | 覆盖报告期各期、含经销商/终端区分、双重身份比对完成 |
| **来源质量** | 仅媒体 | 以公司自述为主 | 招股书/年报为主 | 定期报告 + 问询回复 + 招投标平台 | 一手披露 + 客户方公告/政采平台独立交叉 |
| **对账** | 集中度与收入明显矛盾且未解释 | 期间或分母不一致 | c5×收入 ≈ 前五大金额，差异有 note | 与关联方、供应商名单可对齐 | 客户—订单—收入—关联方四处闭合，双重身份可定位到具体交易 |

## 2. 3 分与 5 分的判据

**3 分**
- `customers[]` 覆盖主要客户，`fullName` 至少半数可核；脱敏客户明确标注。
- `concentration` 有 c1/c5、期间、分母口径；`c5 ≥ c1` 且 0–100。
- `orders`/`bids` 至少各 1 条（确无则说明检索范围）；金额未披露写六态。
- 双重身份若存在，两侧已互相标注。

**5 分**
- 客户名称全部可核到工商全称或证券代码，经销商与终端客户分开标注，同一控制下客户已合并并说明合并依据。
- 集中度给出"公司披露口径"与"统一口径（同分母同期间）"两套，差异有解释；c1 与 c5 可回溯到具体公告段落。
- 订单/中标有平台侧来源（中标公示、客户公告），金额含税与否、履行进度、与收入确认的期间差异均写明。
- 双重身份主体给出两侧交易内容、金额与方向，只列核查动作，不作定性。

## 3. 门与一致性判定（本模块）

| 门/规则 | 含义 | 不过的处理 |
|---|---|---|
| `minEvidence: 3` | 证据 ≥3 条 | 判 2 分（引用准确性） |
| `minCoverage: 0.7` | 必答问题覆盖 ≥70% | 判 2 分（完整性） |
| `minItems.data.customers: 1` | 客户至少 1 行 | 无则插 `not_applicable` 占位并说明 |
| `sixStateFields` | 关系、ID、订单/中标金额、c5 必须落六态 | 空白即判 2 分 |
| `maxEstimatedRatio: 0.2` | 估算 ≤20% | 超限判 2 分 |
| `c5-ge-c1` | c5 必须 ≥ c1 | `block` |
| `concentration-range` | 0–100 | `block` |
| `concentration-period-required` | 有 c5 必须有期间 | `block` |
| `dual-role-tagged` | 客户/供应商交集需标"双重身份" | `block` |
| `order-amount-unit` | 有金额必须有币种 | `attention` |

一致性 `kind` 语义（本模块用到）：`order` 两字段大小关系（`gte/lte`）；`range` 数值区间；`required_with` 条件必填；`tag_required` 交集元素必须带指定标签。六态在标量字段上写在行 `note` 开头（`found｜…`），对象字段可直接写 `{status,value,note}`。

## 4. 一票否决项

1. 编造客户名称、集中度、订单金额、中标项目或 URL。
2. 把框架协议/意向书金额写成订单金额。
3. 用同行客户集中度替代本公司数据。
4. 把客户兼供应商直接定性为"虚增收入/循环交易/造假"。
5. 声称本模块 `stable` 或"专家已审"。
