# 未 stable 方向的最低调查清单 · 客户、订单与招投标

> 用途：预算不足或无法取得完整披露时的最小集合。不降低证据与六态要求。

## 1. 最低必查

1. **前 N 大客户**：招股书或年报取到至少 1 家客户的名称/脱敏标识与占比。
2. **集中度**：取 c1 或 c5 之一，必须带期间与分母口径。
3. **一次客户身份核验**：把可核客户对上工商全称或证券代码。
4. **一条订单或中标记录**：有对手方/项目名与日期；无则记录已检索平台。
5. **一次双重身份比对**：客户名单 ∩ 供应商名单（若 `supply.capacity` 可用）。

## 2. 最低可交付字段

| 字段 | 最低要求 | 不满足时 |
|---|---|---|
| `data.customers[]` | ≥1 行，含 name 与 relation | 无客户信息 → 整模块 `not_reviewed` |
| `data.concentration` | c5 或 c1 + period + note | 无 → `not_disclosed_after_search` |
| `data.orders[]` | 可为空，需说明检索范围 | 空且无说明 → 门不过 |
| `data.bids[]` | 可为空，需说明检索平台 | 同上 |
| `claims` | ≥3 条，≥1 条 material | 证据不足 → 门不过 |

## 3. 必须标注的缺口

- 脱敏客户的真实身份（需企业版合同与发票）。
- 单客户毛利率、单客户回款周期。
- 在手订单明细与订单转化率。
- 经销商→终端客户的穿透。
- 未公开的框架协议与长期供货协议。
- 若为境外客户：合同主体、结算币种、贸易术语（FOB/CIF）。

## 4. 禁止的凑数做法

- 用同行业客户集中度替代。
- 把"战略合作""意向订单"写成已签合同。
- 把经销收入全部归到某一个终端客户。
- 用客户所在行业的平均采购额反推客户金额而不标 `estimated` + derivation。
- 未核名就把品牌名写成工商全称。
