# 未 stable 方向的最低调查清单 · 关联方与关联交易

> 用途：预算/时间不足、或上游未 verified 时，本模块**最低限度**要查什么、能交付什么、必须标注哪些缺口。
> 遵守同一纪律：不编造、不替代、只写核查项；最低清单不降低六态与证据要求。

## 1. 最低必查（30 分钟内可完成的最小集合）

1. **招股书/年报的关联方章节**：至少取到"关联方关系"表与"关联交易"表；记主体名、关系性质、金额、期间。
2. **一笔重大关联交易的公告**：取对手方、方向、金额、定价原则、审批程序。
3. **一次审批程序核验**：董事会/股东大会决议中关联董事或关联股东是否回避。
4. **一次工商交叉**：控股股东或董监高的对外投资/任职，用于识别未在披露清单中的关联企业。
5. **一次客户/供应商名单比对**（若有 `valuechain.parties`）：只记重叠，不定性。

## 2. 最低可交付字段

| 字段 | 最低要求 | 不满足时 |
|---|---|---|
| `data.parties[]` | ≥1 行，含 `name`/`fullName`/`role`/`relation`（带口径） | 无法确认关联方 → 整模块 `not_reviewed` + `openQuestions` |
| `data.transactions[]` | 至少 1 笔重大交易，含金额与期间 | 无公开金额 → `pending_dd`，不得估算 |
| `data.overlapFlags[]` | 可为空数组，但必须说明比对范围 | 未比对 → `not_reviewed` |
| `claims` | ≥4 条，其中 ≥2 条 `material` | 证据不足 → 门不过 |
| `sourceCoverage` | 列出实际检索词与库 | 缺 → 门不过 |

## 3. 必须标注的缺口（写进 `limitations` 与 `openQuestions`）

- 关联自然人及其关系密切家庭成员的完整名单（公开信息通常只能覆盖公告明确表述者）。
- 未达披露门槛的小额关联交易。
- 企业版关联方往来明细账、定价依据的内部审批文件。
- 若只有年报摘要、无附注：单笔金额、期末余额、定价方式。
- 若为 A+H 或多地上市：境外规则口径未并轨。

## 4. 禁止的"凑数"做法

- 用同行公司的关联交易占比推算本公司。
- 把媒体"关联方"表述直接写进 `parties`。
- 把框架协议、意向书金额写成已发生交易。
- 用"通常""据了解""业内普遍"替代来源。
- 在缺口未标注的情况下声称覆盖完整。

## 5. 交付话术（供交付模块引用）

> 本模块为 draft 方法论，未经过金融专家评审。关联方清单以公开披露为限，未覆盖企业版明细；关联交易金额口径与期间已在字段中标注；重叠项仅为核查线索，不构成结论。
