# financials-public · 审核 rubric（五维 1–5 分）

> 适用：`financials.public` 各财年分区的复核。任一维 ≤2 分不通过；本模块为 `draft`。

## 1. 事实准确性

| 分 | 判据 |
|---|---|
| 5 | 三表科目与年报原文逐项一致；单位、币种、期间、合并口径全部写清；归母与净利润未混用 |
| 3 | 主要科目正确，个别附注项缺失或口径只写一半但已说明 |
| 1–2 | 金额与原文不符；单位差 100/10000 倍；把营业总收入当营业收入 |

## 2. 引用准确性

| 分 | 判据 |
|---|---|
| 5 | 每个数字可追到年报页码或附注编号；审计意见为原文摘录；`recon` 的两值都有出处 |
| 3 | 主要数字有出处，个别取自终端但已回原始公告核对 |
| 1–2 | 数字无出处；审计意见是转述而非原文；引用页码与内容不符 |

## 3. 完整性

| 分 | 判据 |
|---|---|
| 5 | 收入、成本、毛利、净利、三表摘要、审计意见、口径、重述、合并范围全覆盖；`recon` ≥7 条 |
| 3 | 主体科目齐全，`recon` ≥3 条，1–2 项写 `insufficient` 并有原因 |
| 1–2 | 只有收入与净利；`recon` 为空或全是"通过"式描述 |

## 4. 来源质量

| 分 | 判据 |
|---|---|
| 5 | 主数据全部取年报全文/招股书原始文件；终端只作索引；旁证标注 authority |
| 3 | 主数据为 A/B 级单源，可核；旁证使用 C 级并标注 |
| 1–2 | 以终端或媒体转述为主数据；未打开年报全文 |

## 5. 对账

| 分 | 判据 |
|---|---|
| 5 | 七项勾稽逐条算出 left/right；毛利率可复算；与 `business.segment` 的收入结构不矛盾；与 `debt-guarantee` 的负债口径一致 |
| 3 | 勾稽算出但缺 1–2 项，或与上游有已知口径差异并已说明 |
| 1–2 | 勾稽只写结论不写数字；毛利率与收入成本算不出来；与上游收入矛盾且未标 `conflict` |

## 记录要求

- 每条扣分写：维度、字段路径（如 `data.recon[2]`）、理由、需补证据；
- 勾稽 `fail` 不是扣分项本身，缺 left/right 或把 `insufficient` 写成 `pass` 才扣分；
- 复核人只能提修订，不得自行改为 `verified`。
