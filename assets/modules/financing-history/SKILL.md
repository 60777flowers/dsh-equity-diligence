# financing-history · 融资历史与估值轨迹

> 模块状态：**draft**。方法论未经金融专家评审，不得声称 `stable` 或"专家已审"。
> 输出底稿：`financing.history`（scope=company，cardinality=one，partitionKey=`_default`）。
> 一句话目标：把"融过几轮、拿了多少钱、谁给的、什么估值、有没有回购"写成一条可对账的时间线。

## 1. 回答什么问题

1. 从设立到现在，发生过几次股权融资？轮次名称、交割时间、金额？
2. 每轮的投后估值是多少？依据是什么（公告、招股书、媒体、工商）？
3. 投资人有谁，领投还是跟投，机构全称与品牌名是否对应？
4. 有没有老股转让（股东套现）？转让方、受让方、价格？
5. 有没有回购/对赌条款？触发条件、义务人、是否已解除？
6. 累计融资额是多少，口径是什么（股权/债权、是否含老股、是否含未交割）？

## 2. 输入、前置与降级

| 关系 | 类型 | 说明 |
|---|---|---|
| 硬输入 | `company.identity` | 全称、曾用名、成立日，用于工商变更检索 |
| 硬输入 | `ownership.chain` | 股东与历次股权变更，用于确定"哪次变更是增资" |
| 软引用 | `business.segment` | 业务阶段，用于判断轮次合理性（如 Pre-IPO 前应有收入） |

- 降级：无 `ownership.chain` 时不得启动（block）；工商变更不可读时，只能靠公告与招股书，轮次可能不全，须在 `openQuestions` 写明。
- 分区：单一 artifact，`{{unit.partition}}` 恒为 `_default`。
- `{{params.includeRepurchase}}`=false 时跳过回购检索，`data.repurchase` 置空数组并在 note 说明。

## 3. 检索计划

### 3.1 来源优先级

| 序 | sourceTier | 典型来源 | 用途 | authority |
|---|---|---|---|---|
| 1 | company | 招股书"股本演变/历次增资"、募集说明书 | 轮次、价格、估值最权威 | B（但为公司申报文件，经中介核查） |
| 2 | announcement | 定增/发行结果公告、权益变动报告书、重大合同 | 金额、价格、投资人 | A |
| 3 | registry | 国家企业信用信息公示系统变更记录（注册资本、股东、日期） | 时间线与增资/转股区分 | B |
| 4 | regulator | 中基协私募基金备案（管理人、基金、投向） | 投资主体性质 | B |
| 5 | database | 商业库融资信息（IT 桔子等） | 索引与线索 | C |
| 6 | media | 36 氪/投资界/财新等融资报道 | 补充轮次与估值 | C |
| 7 | company | 官网新闻、公众号融资稿 | 公司自述 | C（self_reported） |

- `"<公司全称>" 投后估值`、`"<公司全称>" 估值`

### 3.3 英文检索词

`"<English name>" funding round`、`"<English name>" Series A valuation`、`"<English name>" post-money`、`"<English name>" secondary sale`；境外主体加当地语言检索。

### 3.4 必查库与必开页面

- 招股说明书"股本演变""历次增资及股权转让"章节（含价格、定价依据、估值）；
- 巨潮资讯网定增/发行结果/权益变动公告；
- 国家企业信用信息公示系统"变更信息"（注册资本、股东、时间）；
- 中基协私募基金公示（确认投资主体是基金还是自有资金）；
- 商业库融资时间线（只作索引，逐条回原始来源）；
- 裁判文书网"股权回购/股权转让纠纷"（回购条款被触发的证据）。

### 3.5 检索顺序与预算

1. 招股书/公告拿主干轮次（约 5 次）；
2. 工商变更核对时间与金额（约 4 次）；
3. 投资人与基金备案（约 3 次）；
4. 老股与回购（约 4 次）；
5. 媒体补齐（约 2 次）。
上限见 `module.yaml` 的 `budget.toolCallsPerUnit`。

### 3.6 典型来源组合（按主体类型）

| 主体类型 | 轮次来源 | 估值来源 | 补充 |
|---|---|---|---|
| 拟 IPO | 招股书"股本演变" | 招股书披露的增资价格与定价依据 | 审核问询回复 |
| A 股上市公司 | 定增/发行结果公告 | 发行价格与发行后股本 | 权益变动报告书 |
| 新三板挂牌 | 股票发行方案与认购结果 | 发行价格 | 股转公司问询 |
| 非公众公司 | 工商变更 + 融资新闻 | 媒体披露投后估值 | 中基协备案 |
| 境外主体 | 注册地股东登记 + 融资公告 | 境外媒体/官方披露 | 当地语言检索 |

## 4. 字段与口径

| 字段 | 结构 | 定义 | 算 `found` | 算 `not_disclosed_after_search` |
|---|---|---|---|---|
| `data.rounds[]` | `date`/`round`/`amount`/`valuation`/`investors`/`note` | 一次股权融资 | 有日期 + 至少金额或投资人 | 只有"完成融资"文字 |
| `data.valuationMarks[]` | `date`/`postMoney`/`basis`/`note` | 投后估值标记 | 有数值且 `basis` 明确 | 只有"估值翻倍"式表述 |
| `data.repurchase[]` | `clause`/`trigger`/`obligation`/`note` | 回购/对赌条款 | 条款原文可引 | 只有传闻 |

- `round` 用规范词：`种子`/`天使`/`Pre-A`/`A`/`A+`/`B`/`B+`/`C`/`D`/`Pre-IPO`/`战略融资`/`定增`。
- `amount` 写 `{value, currency, unit, kind}` 风格的自由对象，`kind` 取 `equity`/`debt`/`mixed`；无法确认金额时写 `null` 并在 note 说明。
- `valuation` 与 `valuationMarks.postMoney` 必须是**投后**口径；若来源只给投前，换算后在 note 写"投前 X + 本轮 Y = 投后 Z"。
- `investors` 用数组，元素写机构全称，品牌名放括号，例如 `某某创业投资合伙企业（有限合伙）（品牌：某资本）`。

### 4.1 轮次有序

`data.rounds` 必须按 `date` 升序（同日多轮按逻辑先后）；轮次字母序与时间序矛盾时标 `conflict`，不得自行改写轮次名。同一轮分多次交割的，合并为一条并在 note 写"分 N 次交割，日期分别为…"。

### 4.2 金额打折标注

媒体常用"数千万""近亿元""超十亿"。处理规则：
- 有精确数字 → 用数字；
- 只有量级 → 记 `lower_bound`，note 写"媒体表述：'数千万'，取下限"；
- 只有区间 → 记区间并在 note 注明来源与表述；
- 不得把量级表述改成精确数字，也不得在累计融资额里按上限计入。

### 4.3 估值口径

- 投后（post-money）= 投前 + 本轮融资额；只披露投后的，直接记 postMoney；
- 用"融资额 ÷ 出让股比"反推估值，必须同时有融资额与股比两个可核数据，否则 `pending_dd`；
- 不同轮次估值不可直接比较，须注明是否含老股、是否为摊薄后、是否含期权池。

### 4.4 老股转让与增资的区分

工商"注册资本不变、股东变更"通常是老股转让；"注册资本增加"通常是增资。两者都可能是融资的组成部分，但只有增资计入"股权融资额"。老股转让单独记录（转让方、受让方、价格、是否溢价），不并入轮次金额。

### 4.5 回购与对赌

条款来源优先级：招股书"对赌协议"披露 > 公告 > 裁判文书 > 媒体。必须写清：触发条件（IPO 时限、业绩承诺、重大违约）、义务人（创始人/公司/关联方）、义务形式（回购/补偿/优先清算）、是否已解除（含解除时间与方式）。公司作为回购义务人涉及资本维持与可执行性问题，只记录事实并写"需法律核"，不做定性。

### 4.6 累计融资额

只在"已披露、有金额、已交割"的股权融资轮次上求和，并在 note 写口径：是否含债、是否含老股、是否含未交割、是否含 IPO 募资。查不全时写 `lower_bound` + 已知下限，**不得用同行均值替代**。

### 4.7 字段填充示例（占位符，不是真实数据）

```jsonc
{

    {"date": "2021-06", "round": "A", "amount": {"value": 0, "currency": "CNY", "unit": "万元", "kind": "equity"},

     "investors": ["某创业投资合伙企业（有限合伙）（品牌：某资本）"],
```

## 5. 六态与边界

- `found`：有日期 + 金额或估值 + 来源；
- `not_disclosed_after_search`：查过招股书、公告、工商、中基协仍无；
- `lower_bound`：只有量级或下限；
- `pending_dd`：需要增资协议、股东名册、交割凭证；
- `conflict`：媒体与工商/公告金额或时间不一致，保留两组；
- `not_applicable`：无外部股权融资（如纯内资自筹）；
- `not_reviewed`：本轮未查；
- `estimated`：仅允许用于"估值区间"等分析型判断，必须带 `derivation`；单轮金额与股比一律不得 estimated。

边界：不推算未披露的估值；不把战略合作、政府补助、银行授信当融资；不评价估值高低是否合理；不披露投资人的非公开 LP 信息。

## 6. 常见误判

1. 把工商"注册资本增加额"当成融资额（溢价部分在资本公积）。
2. 把媒体"数亿元"写成精确金额，或直接加总进累计融资额。
3. 把投前估值当投后估值。
4. 把老股转让当增资，虚增融资额。
5. 把战略合作协议签署当融资交割。
6. 把 IPO 募资或定增算进私募轮次。
7. 把可转债、可交债当纯股权融资（应标 `kind=mixed/debt`）。
8. 同一轮被多家媒体重复报道，当成多轮。
9. 用"估值翻 N 倍"的媒体表述替代具体估值。

## 7. 验收要点

- 证据：≥5 条；每轮至少 1 条 supports；
- 覆盖：轮次、金额、投资人三项齐全；估值与回购有结论或六态说明；
- 有序：`rounds` 按日期升序，轮次与时间不矛盾；
- 必答：①共几轮、最近一轮时间与金额；②最近一轮投后估值及依据；③主要投资人；④是否有老股转让；⑤是否有回购条款及是否解除；⑥累计融资额及口径；
- 一致性：与 `ownership.chain` 的股东名单、注册资本变化一致；`valuationMarks` 与 `rounds` 的估值不矛盾。

## 8. 与其他模块的关系

- 上游（硬）：`company.identity`、`ownership.chain`；软引用 `business.segment`；
- 下游：`assessment-fit`（估值与股权结构对合作方式的影响）、`red-flags`（回购/对赌触发器）、`deliverable`（融资页）；
- 不重复：股东名单与持股比例归 `ownership.chain`；有息负债归 `debt-guarantee`；估值合理性判断不在本模块。

## 9. 交付前自检

- [ ] 每轮都有日期与来源，轮次名符合词表
- [ ] 估值全部是投后口径，换算过程可读
- [ ] 量级金额标了 `lower_bound`，未进精确加总
- [ ] 累计融资额写清口径
- [ ] 回购条款有原文引用，未定性
- [ ] 全文无 `stable`、`已审` 字样

## 10. 明确不覆盖

- 股权结构穿透与控制权（归 `ownership.chain`）；
- 债权融资与授信（归 `debt-guarantee`）；
- 估值合理性、可比公司倍数（属分析，不在本模块）；
- 投资人的基金业绩与 LP 结构（超出调查范围）。

## 11. 术语速查

| 术语 | 本模块口径 |
|---|---|
| 投前估值 | 本轮交割前公司整体价值，不含本轮资金 |
| 投后估值 | 投前 + 本轮融资额（未考虑期权池与老股因素时须注明） |
| 增资 | 注册资本增加，资金进入公司，计入融资额 |
| 老股转让 | 注册资本不变，股东之间转让，资金不进公司，不计入融资额 |
| 分次交割 | 同一轮协议分多次到账，合并为一条轮次记录 |
| 量级表述 | "数千万/近亿"等，只能记 `lower_bound` 或区间 |
