# {{module.name}} · 采集任务：融资历史与估值轨迹

## 任务

对 **{{company.name}}**（代码 {{company.code}}）梳理历轮股权融资、金额、估值、投资人、老股转让与回购线索。
委托方：{{project.client}}；模块：{{module.name}}；分区：{{unit.partition}}。
产出底稿 `financing.history`，只用公开信息，不做估值判断。

## 输入

- 主体识别：{{artifact:company.identity}}
- 股权与控制链（股东与历次变更）：{{artifact:ownership.chain}}
- 业务阶段（软引用）：{{artifact:business.segment}}

## 参数

- 是否检索回购条款：{{params.includeRepurchase}}
- 剩余预算：{{budget.remaining}}

## 必答问题（每条落到 `data` 或 `openQuestions`）

1. 从设立到现在共发生几次股权融资？分别是哪一轮、什么时间？
2. 每轮金额是多少？是股权融资、债权融资还是混合？
3. 每轮投后估值是多少？依据是哪份文件？是否只给了投前？
4. 投资人有谁？领投/跟投？机构全称与品牌名如何对应？
5. 有没有老股转让？转让方、受让方、价格、溢价情况？
6. 有没有回购/对赌条款？触发条件、义务人、是否已解除？
7. 累计融资额是多少，口径是什么（是否含债、含老股、含未交割）？

## 检索词起点

- `"<公司全称>" 融资` / `"<公司全称>" 完成 A轮` / `"<公司全称>" 战略融资`
- `"<公司全称>" 增资` / `"<公司全称>" 注册资本 变更` / `"<公司全称>" 老股转让`
- `"<公司全称>" 投后估值` / `"<公司全称>" 对赌` / `"<公司全称>" 回购`
- `"<公司全称>" 招股书 股本演变`

## 检索路径（按序执行）

1. 招股说明书"股本演变/历次增资及股权转让"章节；
2. 巨潮资讯网定增、发行结果、权益变动公告；
3. 国家企业信用信息公示系统"变更信息"：注册资本、股东、日期；
4. 中基协私募基金公示：确认投资主体是基金还是自有资金；
5. 裁判文书网"股权回购/股权转让纠纷"：回购被触发的证据；
6. 商业库与财经媒体的融资时间线（只作索引，逐条回原始来源）。

## 输出字段清单

- `data.rounds[]`：date / round / amount / valuation / investors / note
- `data.valuationMarks[]`：date / postMoney / basis / note
- `data.repurchase[]`：clause / trigger / obligation / note

## 口径要求

- `round` 用规范词：种子/天使/Pre-A/A/A+/B/B+/C/D/Pre-IPO/战略融资/定增；
- `rounds` 必须按日期升序；同轮多次交割合并为一条并在 note 说明；
- `valuation` 与 `postMoney` 必须是投后口径；只给投前的，换算后写清"投前 X + 本轮 Y = 投后 Z"；
- 媒体"数千万/近亿"一律 `lower_bound` 或区间，不得改成精确数字；
- 老股转让不并入融资额，单独记录；
- 累计融资额只在"已披露、有金额、已交割"的股权轮次上求和，并写口径。

## 六态写法

- 只有"完成融资"文字：`not_disclosed_after_search` 或 `lower_bound`；
- 需增资协议/交割凭证：`pending_dd`；
- 媒体与工商/公告冲突：`conflict` + 两组值；
- 估值区间推断：可 `estimated`，必须带 `derivation`；
- 单轮金额与股比一律不得 estimated。

## 不要做

- 不推算未披露的估值；不评价估值是否合理；
- 不把战略合作、政府补助、银行授信、可转债当股权融资；
- 不把老股转让当增资；
- 不合并同一轮的多篇报道为多轮；
- 不披露投资人的非公开 LP 信息；
- 不声称已核验或专家已审。
