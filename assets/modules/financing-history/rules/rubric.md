# financing-history · 审核 rubric（五维 1–5 分）

> 适用：`financing.history` 底稿复核。任一维 ≤2 分不通过；本模块为 `draft`。

## 1. 事实准确性

| 分 | 判据 |
|---|---|
| 5 | 轮次、日期、金额、估值、投资人与招股书/公告逐项一致；投前投后口径无混淆；老股与增资未混 |
| 3 | 主干轮次正确，个别轮次金额为媒体口径但已标 `lower_bound` 并说明 |
| 1–2 | 把注册资本增加额当融资额；把投前当投后；把老股转让算进融资额 |

## 2. 引用准确性

| 分 | 判据 |
|---|---|
| 5 | 每轮至少 1 条 evidence；金额与估值能追到公告/招股书页码或工商变更记录；回购条款为原文引用 |
| 3 | 主干有证据，个别轮次只有媒体来源并已标 authority=C |
| 1–2 | 轮次无出处；金额来自"某媒体称"而无链接；回购条款为转述 |

## 3. 完整性

| 分 | 判据 |
|---|---|
| 5 | 轮次、金额、投资人、估值、老股、回购六项齐全；累计融资额与口径已给 |
| 3 | 六项中四项有结论，缺项写了 `not_disclosed_after_search` 与检索记录 |
| 1–2 | 只有最近一轮；老股与回购完全未查且未说明 |

## 4. 来源质量

| 分 | 判据 |
|---|---|
| 5 | 主数据取招股书/公告/工商；媒体只补缺；同一新闻稿的转载未当多源 |
| 3 | 主要依赖工商 + 媒体两源交叉，可接受 |
| 1–2 | 全部依赖商业库或自媒体；用转载稿冒充独立双源 |

## 5. 对账

| 分 | 判据 |
|---|---|
| 5 | 轮次日期升序；与 `ownership.chain` 的股东与注册资本变化一致；估值标记与轮次不矛盾；累计额可复算 |
| 3 | 有 1 处口径差异（如四舍五入、月份归属）且已说明 |
| 1–2 | 轮次时间与工商变更冲突未标 `conflict`；累计融资额无法复算 |

## 记录要求

- 每条扣分写：维度、轮次（如 `data.rounds[1]`）、理由、需补证据；
- 金额为区间或量级时，扣分只看是否标注，不看数值大小；
- 复核人只能提修订，不得自行改为 `verified`。
