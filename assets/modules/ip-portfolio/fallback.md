# 未 stable 方向的最低调查清单 · 知识产权组合

> 用途：预算不足或无法访问全部官方库时的最小集合。不降低证据与六态要求。

## 1. 最低必查

1. **母公司专利清单**：CNIPA 按申请人检索，取到申请号、状态、申请日。
2. **一次官方状态核验**：至少 1 件核心专利在 CNIPA 登记簿/审查信息查询确认状态与检索日。
3. **子公司与曾用名**：至少对 1 个主要子公司在 CNIPA 单独检索，确认是否有专利。
4. **商标**：中国商标网按申请人检索，取注册号与状态。
5. **软著**：中国版权保护中心按著作权人检索，取登记号。
6. **质押**：CNIPA 质押登记检索一次，记录有/无。

## 2. 最低可交付字段

| 字段 | 最低要求 | 不满足时 |
|---|---|---|
| `data.patents[]` | ≥1 行，含 number/status/applicant | 确无 → 1 行 `not_applicable` 占位 + 检索式 |
| `data.trademarks[]` | 可为空，需说明检索范围 | 空且无说明 → 门不过 |
| `data.software[]` | 可为空，需说明检索范围 | 同上 |
| `data.pledges[]` | 可为空，需说明已检索质押登记 | 同上 |
| `claims` | ≥3 条，≥1 条 material | 证据不足 → 门不过 |

## 3. 必须标注的缺口

- 未覆盖的子公司/境外主体。
- 申请日起 18 个月内尚未公开的专利申请。
- 权利要求全文与独立权利要求数量（只取到摘要时）。
- 同族与引证（未连 Espacenet/INPADOC 时）。
- 许可备案（未查 CNIPA 合同备案时）。
- 专利维持费缴纳与年费状态（登记簿未实时更新时）。

## 4. 禁止的凑数做法

- 用 Google Patents 的聚合数字当官方数量。
- 把同族多国成员分别计数。
- 把申请量写成"授权专利"。
- 把软著登记当技术壁垒。
- 用同行业平均专利数替代。
- 对权利要求做侵权判断。
