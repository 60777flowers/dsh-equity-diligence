# {{module.name}} · 采集任务：司法风险

## 任务

对 **{{company.name}}**（代码 {{company.code}}）及其子公司、关键人，检索近 {{params.yearsBack}} 年的诉讼、执行、失信、股权冻结与破产线索。
委托方：{{project.client}}；模块：{{module.name}}；分区：{{unit.partition}}。
产出底稿 `legal.risk`，只记录事实与状态，不下法律结论。

## 输入

- 主体识别（全称、代码、曾用名、注册地）：{{artifact:company.identity}}
- 股权与控制链（子公司清单）：{{artifact:ownership.chain}}
- 关键人名单（软引用）：{{artifact:org.people}}

## 参数

- 回溯年限：{{params.yearsBack}} 年（早于窗口但仍在执行的案件必须收录）
- 剩余预算：{{budget.remaining}}

## 必答问题（每条落到 `data` 或 `openQuestions`）

1. 近 {{params.yearsBack}} 年公司及子公司有多少诉讼/仲裁案件？主要案由是什么？
2. 涉案金额最大的三件是什么？诉请、判决、执行标的分别是多少？现在什么状态？
3. 是否被列为被执行人、失信被执行人、限制高消费？
4. 是否存在股权冻结、资产查封？冻结主体与金额？
5. 是否涉及破产重整、和解、清算或预重整？
6. 实控人、法定代表人、董监高个人是否有刑事、民事、执行记录？
7. 每件案件的胜败与履行情况如何（已生效/已履行/未履行）？

## 检索词起点

- `"<公司全称>" 判决书` / `"<公司全称>" 裁定书` / `"<公司全称>" 开庭公告`
- `"<公司全称>" 被执行人` / `"<公司全称>" 失信` / `"<公司全称>" 限制高消费`
- `"<公司全称>" 股权冻结` / `"<公司全称>" 破产重整`
- `"<子公司全称>" 诉讼`（逐个主要子公司）
- `"<关键人姓名>" "<公司简称>" 判决`

## 检索路径（按序执行）

1. 中国裁判文书网：按当事人 + 案由 + 法院层级；
2. 中国执行信息公开网：被执行人、失信、限高、终本；
3. 全国企业破产重整案件信息网：重整/清算/预重整；
4. 人民法院公告网与各地法院开庭公告：送达、开庭、拍卖、破产；
5. 上市公司公告与年报"重大诉讼、仲裁事项"（用于金额与进展）；
6. 关键人个人检索（≤5 人）。

## 输出字段清单

- `data.litigation[]`：caseId / court / parties / cause / amount / stage / status / date / note
- `data.enforcement[]`：caseId / court / amount / status / date / note
- `data.dishonest[]`：person / caseId / status / note
- `data.frozen[]`：subject / amount / status / note

## 口径要求

- `stage` 只用：立案/一审/二审/再审/执行/终本/已结案；
- `status` 只用：审理中/已生效/已履行/未履行/部分履行/已撤诉/已驳回/unknown；
- `amount` 必须写口径（诉请/判决/执行标的/和解）与币种；
- `parties` 写"原告/被告/第三人 + 名称"；
- 每条记录写主体匹配依据（统一社会信用代码 / 注册地+法定代表人 / 曾用名）；
- 区分三类：**已裁定**（生效判决/执行）、**指控**（起诉书/仲裁申请）、**自述**（公司公告）。

## 六态写法

- 只有媒体提及：`not_disclosed_after_search` 或进 `openQuestions`，不写入 `data.litigation`；
- 只知金额下限：`lower_bound`；
- 需判决书全文/和解协议：`pending_dd`；
- 公告与文书金额冲突：`conflict` + 两组值；
- 确认无案件：`not_applicable` + 检索范围与日期；
- 诉讼敞口汇总：可 `estimated`，必须带 `derivation`；个案金额与状态不得 estimated。

## 不要做

- 不判断胜诉概率、不出法律意见；
- 不把"被起诉"写成"违法"，不把"被告"写成"败诉"；
- 不把同名公司案件算到主体头上；
- 不只查母公司而漏掉子公司与关键人；
- 不采集当事人身份证号、住址等个人信息；
- 不声称已核验或专家已审。
