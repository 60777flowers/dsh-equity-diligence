# 兜底清单 · 股权穿透（未 stable 方向的最低调查）

> 适用：未上市公司工商快照不全、境外层级不可查、公告未披露实控人、预算不足以穿透到自然人。
> 兜底不降低“不编造”的要求：宁可停层写 `pending_dd`，不写推测。模块状态 `draft`。

## 1. 最低必做（五项）

1. **第一层股东名单**：至少列出全部直接股东及各自比例，来源与披露日可回查。
2. **一个控制结论或明确的“未披露”**：控股股东/实际控制人有公告表述就写并引原文；
   没有就写 `not_disclosed_after_search`，并列查过的公告库与关键词。
3. **一次穿透尝试**：至少向上再展开一层；停在哪一层、为什么停，必须写清。
4. **一次一致行动核查**：公告、权益变动书、章程中检索“一致行动/表决权委托”，有则列，无则写已查。
5. **合计校验**：`capTable` 合计与 100% 的差额，写清来源（未披露/库存股/员工持股/境外层）。

## 2. 分场景下限

| 场景 | 最低动作 | 允许的六态 |
|---|---|---|
| 上市公司 | 最新年报/权益变动公告股东表 + 实控人表述 | `found` |
| 拟上市公司 | 招股书“股本结构/股东情况”章节 + 反馈回复 | `found` / `pending_dd` |
| 未上市有限公司 | 工商快照股东 + 出资额；合伙企业继续查合伙人 | `found` / `pending_dd` |
| 多层合伙企业 | 逐层查到自然人或国资/境外主体，或写到停因 | `pending_dd` |
| 境外/红筹层 | 当地登记 + 上市公告；不可查时停层 | `not_disclosed_after_search` |
| 股权分散无实控 | 写“无实际控制人”并给依据（分散度、无一致行动、董事会结构） | `found` |
| 预算耗尽 | 保留已得层级，其余 `not_reviewed`，写恢复点 | `not_reviewed` |

## 3. 特殊权利与历史的兜底

- 特殊权利至少查三处：公司章程、招股书特别表决权/对赌章节、投资协议公开披露片段。
- 三处都没有 → `pending_dd`，写“需企业提供投资协议/章程”与已查位置。
- 历史变更至少覆盖近三年；早期无公开记录写 `not_reviewed`，不推测。
- 已解除/已到期条款必须标状态，不得当作现存权利。

## 4. 必须写进底稿的三句话

- 穿透停在哪一层、为什么停、缺什么材料能继续。
- 合计差额来自哪里、对控制结论有没有影响。
- 下一步由谁、用什么材料补（章程、股东名册、合伙协议、企业版数据库）。

## 5. 明确不做

- 不用同行股权结构替代本公司结构。
- 不把 GP 当实控人，不把持股平台当自然人。
- 不因差额凑数，不把 `pending_dd` 写成 `found`。
- 不在兜底模式下宣称“已穿透至最终受益人”。
