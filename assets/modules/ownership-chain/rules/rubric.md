# 审核 rubric · 股权、控制权与特殊权利

> 五维各 1–5 分；**任一维 ≤2 分即不通过**。评分看底稿与证据原文，不看叙述是否流畅。
> 模块状态 `draft`：本 rubric 尚未经金融专家评审。

## 1. 事实准确性（持股与控制）

| 分 | 判据 |
|---|---|
| 5 | 第一大股东、前五大合计、股东数、实控人四项与公告逐项一致；直接/间接/合计三者自洽；控制基础写明且与公告口径一致 |
| 4 | 四项齐全，个别数字只有工商口径但已标注来源与日期 |
| 3 | 主要比例正确，但有一项口径未标（股权/表决权、母公司/合并）或股东数只能给下限 |
| 2 | 出现 GP 当实控人、表决权当经济比例、控制结论与公告相反之一 |
| 1 | 持股结构错误或控制结论无依据 |

## 2. 引用准确性（证据）

| 分 | 判据 |
|---|---|
| 5 | 每条比例与控制结论都有 `supports`，公告原文片段 + 页码/章节可回查；一致行动与特殊权利均引原文 |
| 4 | 主要结论有引文，个别条款只到公告标题级 |
| 3 | 比例有引文，但特殊权利或历史变更中 1–2 条为转述 |
| 2 | 控制结论只有媒体来源，或引文无法在快照命中 |
| 1 | 无引文、编造公告编号或比例 |

## 3. 完整性（穿透与条款）

| 分 | 判据 |
|---|---|
| 5 | 穿透到自然人/国资/境外层且停因清楚；一致行动、特殊权利、近三年变更、员工持股平台均已查；`ubo` 与 `control` 分列 |
| 4 | 上述齐全，境外层或历史早期变更之一标 `pending_dd` |
| 3 | 缺一致行动或特殊权利其中一项，但已在 `openQuestions` 说明 |
| 2 | 只写第一层股东，未穿透；或特殊权利整块缺失 |
| 1 | 只有股东名单，没有控制结论 |

## 4. 来源质量（source quality）

| 分 | 判据 |
|---|---|
| 5 | 以权益变动公告/招股书/章程为主，工商交叉；合伙企业逐层查到合伙人；境外层有英文检索记录 |
| 4 | A+B 为主，个别层级只有工商快照 |
| 3 | 主要依赖工商快照，公告仅作点缀 |
| 2 | 多数结论依赖媒体或第三方解读 |
| 1 | 依赖传闻或不可回查页面 |

## 5. 对账（consistency）

| 分 | 判据 |
|---|---|
| 5 | `capTable` 合计 99–101% 且有差额说明；`totalPct=directPct+indirectPct`；变更前后比例可闭合；控制结论与历史一致 |
| 4 | 合计通过，个别差额说明不完整 |
| 3 | 合计在容差外但已标 `conflict` 并说明原因 |
| 2 | 合计硬凑 100%，或变更前后比例无法闭合 |
| 1 | 底稿内部自相矛盾且无说明 |

## 判定与记录

- 五维分数与扣分点写入底稿 `checks[]`；扣分点必须挂 `claimId`/`evidenceId`。
- 任一维 ≤2：退回补查，不得进入 `investment-map` 与 `red-flags`。
- 3 分：可交付，但摘要须标注“比例口径存在局限”。
- 5 分：可直接被报告与工作簿引用，无需二次核验。
