# workforce · 审核 rubric（五维 1–5 分）

> 适用：`workforce.profile` 底稿复核。任一维 ≤2 分不通过；本模块为 `draft`，rubric 未经验证专家评审。

## 1. 事实准确性

| 分 | 判据 |
|---|---|
| 5 | 人数、结构、社保、薪酬数字与年报/工商年报原文一致；每个数字都带口径（期末/平均、合并/母公司）与时点 |
| 3 | 核心数字正确，个别分项缺失或口径只写了一半但已在 note 说明 |
| 1–2 | 把工商从业人数当在职员工数；把母公司人数当合并；数字与原文不符 |

## 2. 引用准确性

| 分 | 判据 |
|---|---|
| 5 | 每类数字都有 evidenceId，locator 到年报章节或工商年报年度；招聘数据带抓取日期与页面 |
| 3 | 主要数字有证据，个别分项只挂聚合页 |
| 1–2 | 数字无出处；引用页码与原文不符；把搜索摘要当证据 |

## 3. 完整性

| 分 | 判据 |
|---|---|
| 5 | 人数、结构、社保、人效、招聘五项齐全；社保与人数差异有解释；近三年趋势可读 |
| 3 | 五项中四项有结论，缺项写了 `not_disclosed_after_search` 与检索记录 |
| 1–2 | 只有一个人数；社保与人效完全未查且未说明 |

## 4. 来源质量

| 分 | 判据 |
|---|---|
| 5 | 人数双源（年报 + 工商年报/招股书）；社保取官方年报；招聘只用平台原始页 |
| 3 | 关键数字单源但为 A/B 级；C 级只作补充 |
| 1–2 | 依赖媒体转述或员工社区帖子；用二手汇总数据替代原始披露 |

## 5. 对账

| 分 | 判据 |
|---|---|
| 5 | 分项之和与总数一致；人数口径与 `financials.public` 合并范围一致；人效算法可复算 |
| 3 | 存在 <5% 的分项差额且已说明 |
| 1–2 | 分项之和与总数矛盾未说明；人均营收与财报营收口径冲突 |

## 记录要求

- 每条扣分写：维度、字段路径、理由、需补证据；
- 不得以"数据较少"为由给出 3 分以上；
- 复核人只能提修订，不得自行改为 `verified`。
