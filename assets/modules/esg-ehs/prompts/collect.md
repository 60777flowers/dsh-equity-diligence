## 检索路径（按序执行）

1. 全国排污许可证管理信息平台：正本、副本、执行报告；
2. 省/市生态环境局：环评受理与审批公示、验收公示；
3. 企业环境信息依法披露系统：年度环境信息报告；
4. 应急管理部门：安全生产许可、事故调查报告、处罚公示；
5. 全国碳市场/地方碳市场：重点排放单位名单与履约情况；
6. 年报"环境信息"与 ESG 报告核对数据口径。

## 输出字段清单

- `data.permits[]`：kind / number / validTo / note
- `data.eia[]`：project / approval / capacity / date / note
- `data.energy[]`：year / consumption / intensity / note
- `data.safety[]`：incident / date / status / note

## 口径要求

- `permits.kind` 用固定词：排污许可证（重点管理）/ 排污许可证（简化管理）/ 排污登记 / 安全生产许可证 / 危险化学品经营许可证 / 危险废物经营许可证 / 消防验收；
- `eia.capacity` 必须带单位，并注明"设计产能"；
- `energy.consumption` 写"数量 + 单位 + 口径"（折标煤/用电量），与 `intensity` 分开；
- `safety.status` 用：已结案 / 调查中 / 整改中 / 无事故记录；
- 三口径（环评设计产能、许可核定产能、实际产量）必须写出对账结论。

## 六态写法

- 只有"已通过环评"文字：`not_disclosed_after_search` + 查过的公示页面；
- 只知许可排放量上限：`lower_bound`；
- 需环评报告全本/执行报告/事故调查报告：`pending_dd`；
- 环评产能与许可产能不一致：`conflict` + 两组值；
- 无生产场所的行业：`not_applicable` + 依据；
- 能耗强度等派生值：可 `estimated`，必须带 `derivation`；许可证号、批复文号、事故结论不得 estimated。

## 不要做

- 不做环保与安全的违法认定，只写"线索 + 需核"；
- 不把环评批复当排污许可证；
- 不把设计产能当实际产量；
- 不用第三方 ESG 评分替代监管事实；
- 不把环保处罚在本模块重复记录（归 `regulatory-compliance`）；
- 不声称已核验或专家已审。
