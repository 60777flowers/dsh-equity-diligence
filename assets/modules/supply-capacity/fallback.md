# 未 stable 方向的最低调查清单 · 供应链、产能与成本

> 用途：预算不足或只能取到公开披露时的最小集合。不降低证据与六态要求。

## 1. 最低必查

1. **前 N 大供应商**：至少 1 家的名称、采购内容、金额或占比、期间。
2. **单一来源**：公司是否披露"唯一/独家/进口依赖"；有则记录影响与替代方案。
3. **产能与产量**：至少一个产品的产能与产量（同期间同单位），或明确写未披露。
4. **一次第三方交叉**：环评批复产能或排污许可产能（取一条即可）。
5. **成本结构**：至少取到"直接材料占比"一项，或明确写未披露。

## 2. 最低可交付字段

| 字段 | 最低要求 | 不满足时 |
|---|---|---|
| `data.suppliers[]` | ≥1 行，含 name/role/relation | 无信息 → 整模块 `not_reviewed` |
| `data.singleSource[]` | 可为空，但需说明检索结论 | 空且无说明 → 门不过 |
| `data.capacity[]` | ≥1 行，含 product/period/单位 + 至少一项产能或产量 | 无 → `not_disclosed_after_search` |
| `data.costStructure[]` | 可为空数组；有则合计 100%±2pp | 无 → 说明未拆原因 |
| `claims` | ≥3 条，≥1 条 material | 证据不足 → 门不过 |

## 3. 必须标注的缺口

- 产线级设计/有效产能与良率损耗。
- 单一供应商的替代认证计划与切换周期。
- 外协加工单价与占比。
- 成本分项的明细账（招股书只给大项）。
- 环评分期批复与预留产能的对应关系。
- 若为进口依赖：管制清单版本、许可状态、库存周转。

## 4. 禁止的凑数做法

- 用设备台数×理论节拍自行推算"公司产能"并写成 `found`。
- 把环评"规划产能"当实际有效产能。
- 把外协厂产能计入自有产能。
- 用同行成本结构替代本公司成本结构。
- 用设计产能做分母算稼动率却不标注。
