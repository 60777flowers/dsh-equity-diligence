# 未 stable 方向的最低调查清单 · 行业空间与竞争格局

> 用途：预算不足或只能取到公开摘要时的最小集合。不降低证据与六态要求。

## 1. 最低必查

1. **一个年份的规模**：至少一个机构的公开摘要（含年份、地域、计量、环节）。
2. **第二个来源**：另一家机构或政府/协会数据；同一报告的转载不算。
3. **一个增速**：CAGR 或 YoY，带区间年份；预测值标 `predicted`。
4. **对手名单**：至少 3 家主要对手及份额（可为区间或 `estimated`）。
5. **一条政策**：文件全称、发文机关、日期、影响方向。

## 2. 最低可交付字段

| 字段 | 最低要求 | 不满足时 |
|---|---|---|
| `data.marketSize[]` | ≥2 行，年/规模/来源口径齐 | 不足 → 门不过（无法双源） |
| `data.competition[]` | ≥1 行，含 name 与 sharePct 或六态 | 无 → `not_disclosed_after_search` |
| `data.share[]` | 可为空，需说明未取得公司份额 | 空且无说明 → 门不过 |
| `data.policy[]` | ≥1 行 | 无 → `not_disclosed_after_search` 并列出检索渠道 |
| `claims` | ≥3 条，≥1 条 material | 证据不足 → 门不过 |

## 3. 必须标注的缺口

- 付费报告的完整方法论与分项拆分。
- 细分环节（而非全行业）的规模与份额。
- 国产化率的口径定义（多数来源口径不一）。
- 公司份额的第三方口径（多为自算）。
- 政策对需求/供给的量化影响（通常只能定性）。
- 若为境外市场：汇率口径、统计口径（产值 vs 出货额）。

## 4. 禁止的凑数做法

- 用媒体标题数字当机构原始数据。
- 把两家媒体转述同一份报告当作双源。
- 把 TAM 当公司可及市场。
- 把预测值写成已发生事实。
- 用同行份额替代本公司份额。
- 把行业增速与公司增速混为一谈。
