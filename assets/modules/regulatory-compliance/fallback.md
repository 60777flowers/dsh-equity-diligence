# regulatory-compliance · 降级调查清单（未 stable 方向）

> 适用：公示系统不可达、主体为非公众公司、或预算不足时的最低交付标准。

## 触发条件

- 信用中国或公示系统访问受限、需验证码；
- 无行业专项主管部门（如纯软件企业无环保/安全监管）；
- 本单元可用工具调用 < 6 次。

## 最低必查（缺一即不得进入 `verified`）

1. 信用中国或公示系统的一次行政处罚检索（有/无都要有结论）；
2. 经营异常名录与严重违法失信名单检索；
3. 纳税信用等级或"未参评/未公示"的明确结论；
4. 海关信用或"无进出口业务"的明确结论；
5. 上市公司/发债主体的证券监管措施检索（问询、警示函、纪律处分）。

## 降级后的写法

- 平台不可达：`not_reviewed` + 说明"平台访问受限"，不得写"无处罚"；
- 只有汇总数据：`data.penalties` 逐条列出已知项，`status` 标 `unknown` 并在 note 说明；
- 纳税信用无公示：`level` 填 `not_disclosed_after_search` + note 写查询的年份与渠道；
- 无进出口：`customsCredit.level` = `not_applicable` + note 说明依据；
- 行业专项未覆盖：在 `openQuestions` 写明缺哪个部门。

## 必须写入 `openQuestions`

- 近三年全部行政处罚决定书与缴款凭证；
- 纳税信用各年度评价结果与扣分原因；
- 海关认证状态与最近一次重新认证时间；
- 在立案调查事项的进展；
- 经营异常/严重违法失信的移出证明。

## 不得做

- 不得把"未查到"写成"无违法违规"；
- 不得用"行业普遍合规"替代；
- 不得把监管问询计入处罚数量；
- 不得在降级产物上写"合规良好"或"已核验"。
