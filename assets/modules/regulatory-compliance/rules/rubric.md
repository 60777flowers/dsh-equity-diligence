# regulatory-compliance · 审核 rubric（五维 1–5 分）

> 适用：`regulatory.compliance` 底稿复核。任一维 ≤2 分不通过；本模块为 `draft`。

## 1. 事实准确性

| 分 | 判据 |
|---|---|
| 5 | 处罚主体、日期、事项、金额、状态与决定书/公示一致；信用等级与评价期正确；处罚/问询/异常未混 |
| 3 | 主要处罚正确，个别金额或状态滞后但已注明日期 |
| 1–2 | 把问询当处罚；把 A 级当无问题；信用等级年度错；子公司与母公司串记 |

## 2. 引用准确性

| 分 | 判据 |
|---|---|
| 5 | 每条记录有公示页面或决定书编号，locator 到栏目；金额与状态可回原文 |
| 3 | 主要记录有证据，个别取自商业库并标 authority=C |
| 1–2 | 记录无出处；金额来自媒体；引用页面与内容不符 |

## 3. 完整性

| 分 | 判据 |
|---|---|
| 5 | 信用中国、公示系统、税务、海关、行业专项五路都查；处罚/信用/异常/问询四类齐全；子公司覆盖有说明 |
| 3 | 四类齐全但行业专项缺一路，已写 `openQuestions` |
| 1–2 | 只查信用中国一路；海关与纳税信用完全未查且未说明 |

## 4. 来源质量

| 分 | 判据 |
|---|---|
| 5 | 全部取官方公示或决定书原文；商业库只作索引；未把转载当独立源 |
| 3 | 主数据官方，个别补商业库并标注 |
| 1–2 | 以商业聚合或媒体为主；未打开任何官方页面 |

## 5. 对账

| 分 | 判据 |
|---|---|
| 5 | 与 `legal-risk` 的诉讼不重复计数；与 `esg-ehs` 的环保安全处罚一致；与 `financials.public` 的营业外支出方向不矛盾 |
| 3 | 有 1 处归类差异（如同一事项既属处罚又属诉讼）且已说明 |
| 1–2 | 同一处罚在两模块金额不同且未标 `conflict`；处罚数量与年报披露差 2 条以上未解释 |

## 记录要求

- 每条扣分写：维度、记录（决定书编号或 `data.penalties[i]`）、理由、需补证据；
- "未查到"与"没有处罚"必须区分，扣分只看是否写清检索范围与日期；
- 复核人只能提修订，不得自行改为 `verified`。
