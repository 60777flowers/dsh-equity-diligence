# policy-exposure · 审核 rubric（五维 1–5 分）

> 适用：`policy.exposure` 底稿复核。任一维 ≤2 分不通过；本模块与底稿类型均为 `draft`，输出只作核查线索。

## 1. 事实准确性

| 分 | 判据 |
|---|---|
| 5 | 清单名称、条目编号、列入日期、匹配字段与官方页面逐项一致；物项分类引用了官方条目；无一处把近似当命中 |
| 3 | 主要结论正确，个别条目只有清单名称而无编号，已标 `pending_dd` |
| 1–2 | 把媒体消息当命中；把 CSL 聚合命中当实体清单；ECCN 凭猜测填写 |

## 2. 引用准确性

| 分 | 判据 |
|---|---|
| 5 | 每条命中都能打开原始清单页面；`listVersion` 写清抓取日；联邦公报引用到规则编号与生效日 |
| 3 | 主要命中可核，个别只挂 CSL 检索结果页 |
| 1–2 | 命中无出处；引用日期与清单版本不符；用了二手汇编当官方来源 |

## 3. 完整性

| 分 | 判据 |
|---|---|
| 5 | 美国/欧盟/联合国/中国四套口径都查；主体、交易对手、物项三维度都有结论；未命中也有检索记录 |
| 3 | 四套口径齐全但交易对手维度缺失，已写 `openQuestions` |
| 1–2 | 只查美国一套；未命中的结论完全没记录 |

## 4. 来源质量

| 分 | 判据 |
|---|---|
| 5 | 全部取官方清单与联邦公报；公司披露只作自述；媒体只作线索 |
| 3 | 主要取官方，个别取权威律所/行业汇编并标注 |
| 1–2 | 以媒体或行业汇编为主；未打开任何官方清单页面 |

## 5. 对账

| 分 | 判据 |
|---|---|
| 5 | 与 `valuechain.parties` 的客户供应商一致；与 `qualifications` 的进出口资质一致；与 `supply.capacity` 的关键设备来源一致 |
| 3 | 有 1 处主体范围差异（子公司是否纳入）且已说明 |
| 1–2 | 客户名单与上游矛盾未标 `conflict`；许可证状态与资质模块冲突 |

## 记录要求

- 每条扣分写：维度、清单或字段（如 `data.listings[0]`）、理由、需补证据；
- 不得因"未命中"给出低分；未命中只要有检索记录即为合格；
- 复核人只能提修订，不得自行改为 `verified`，也不得据本模块结论否决交易。
