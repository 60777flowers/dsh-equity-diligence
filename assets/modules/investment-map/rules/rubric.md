# 审核 rubric · 对外投资版图

> 五维各 1–5 分；**任一维 ≤2 分即不通过**。评分看分区底稿与证据原文。
> 模块状态 `draft`：本 rubric 尚未经金融专家评审。

## 1. 事实准确性（平台、实体、比例）

| 分 | 判据 |
|---|---|
| 5 | 平台全称/角色/编号正确；实体名称与工商全称一致；直接+间接=合计；已退出标的标状态与时间；无一处与公告矛盾 |
| 4 | 上述基本正确，个别实体只有工商口径但已标注 |
| 3 | 平台与实体正确，但 1–2 个比例口径未标（直接/间接、母公司/合并） |
| 2 | 出现方向错误（把股东/出资人写成平台）、间接当直投、已退出当在持之一 |
| 1 | 平台或实体大面积错配，比例无法追溯 |

## 2. 引用准确性（证据）

| 分 | 判据 |
|---|---|
| 5 | 每个平台 ≥3 条证据且覆盖“存在/出资或控制/对外投出”三类中的至少两类；引文与 locator 可回查；转载已按 originGroupId 去重 |
| 4 | 每平台 ≥3 条，个别证据只到公告标题级 |
| 3 | 多数平台 ≥3 条，1–2 个平台只有 2 条并已标 `attention` |
| 2 | 多个平台证据不足 3 条，或证据与平台不匹配 |
| 1 | 无证据，或编造备案号/注册号 |

## 3. 完整性（九类与路径）

| 分 | 判据 |
|---|---|
| 5 | 九类各至少一轮检索并留痕；四维度审核（基准/家族/境外/归位）均做过；每个实体有完整路径；多路径在涉及平台均有行 |
| 4 | 九类覆盖，境外或家族维度之一不完整但已说明 |
| 3 | 缺一类且未说明，或部分实体路径缺中间层 |
| 2 | 只覆盖直投与海外两类，家族/基金类未查 |
| 1 | 只有平台清单，没有被投实体 |

## 4. 来源质量（source quality）

| 分 | 判据 |
|---|---|
| 5 | 公告/招股书/备案为主，工商交叉；境外主体有英文检索与当地登记；基金有中基协备案记录 |
| 4 | A+B 为主，个别平台依赖媒体线索并已回核 |
| 3 | 主要依赖工商快照与媒体盘点 |
| 2 | 多数平台来自媒体榜单，未回公告核名 |
| 1 | 依赖传闻或无法回查的页面 |

## 5. 对账（consistency）

| 分 | 判据 |
|---|---|
| 5 | 编号连续稳定；summary 的 platformCount/entityCount 与分区一致；同一实体多路径在各表均有行且比例不重复相加；方向违规为 0 |
| 4 | 对账通过，个别 `evidenceSummary` 与证据数不一致 |
| 3 | 计数差 1–2 且已说明，或编号有跳号但记录了原因 |
| 2 | 编号重复/更名新建号，或 summary 与分区数量不符 |
| 1 | 同一实体多路径被去重成一行，导致交付表缺行 |

## 判定与记录

- 五维分数与扣分点写入底稿 `checks[]`，扣分点挂 `claimId`/`evidenceId`。
- 任一维 ≤2：退回补查，不得进入 `deliverable`。
- 3 分：可交付，但摘要须标注“平台清单可能不完整，缺哪一类”。
- 5 分：可直接用于 7+N 分表与工作簿，无需二次核验。
