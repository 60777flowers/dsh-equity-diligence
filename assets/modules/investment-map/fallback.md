# 兜底清单 · 对外投资版图（未 stable 方向的最低调查）

> 适用：年报未出、基金备案不全、境外层不可查、预算只够覆盖核心平台。
> 兜底不改变方向口径，也不降低“不编造”的要求。模块状态 `draft`。

## 1. 最低必做（每平台四项）

1. **一个可回查的平台身份**：全称 + 角色（GP/管理人/主导LP/财务LP/直投/境外/合资/基地/家族）。
2. **一条 A公司系的出资或控制证据**：股权比例、LP 份额、GP 归属、控股关系之一。
3. **至少一个被投实体 + 完整路径**：`A公司 → P01 → E01`，中间层不省略。
4. **编号与状态**：`P01` 形式编号；在持/已退出/待核 三态至少一个，退出写时间。

不足 3 条证据的平台允许产出，但必须 `evidenceSummary` 写缺口并 `flags` 标 `attention`。

## 2. 分场景下限

| 场景 | 最低动作 | 允许的六态 |
|---|---|---|
| 上市公司本部直投 | 年报“主要控股/参股公司”+ 公告 | `found` |
| 产业基金（GP/LP） | 公告 + 中基协备案（基金全称/管理人/备案号） | `found` / `pending_dd` |
| 财务 LP | 公告出资额/比例 + 基金全称 | `found` |
| 境外平台 | 招股书“公司架构”+ 当地登记/英文检索 | `pending_dd` |
| 家族平台 | 权益变动/工商关联企业 + 公开报道回核 | `pending_dd` / “疑似，未证实” |
| 已退出 | 退出公告或工商变更 | `found` + status 已退出 |
| 预算耗尽 | 保留已得平台，其余 `not_reviewed`，写恢复点 | `not_reviewed` |

## 3. 九类的最低覆盖

- 九类各做一轮检索并留痕；某类确认为空时，在 `openQuestions` 写“查过什么、为什么为空”。
- 至少覆盖第 1、2/3、5、8/9 类四组，否则视为版图不成立。
- 家族类无公开平台时写“无公开平台线索”，不得省略整类。

## 4. 必须写进底稿的三句话

- 哪几类可能不完整、缺什么、对“平台清单完整性”的影响。
- 哪个平台只有单一来源、建议如何补（备案、合伙协议、境外注册证书）。
- 哪些平台/实体是“疑似，未证实”，下一步怎么核。

## 5. 明确不做

- 不查“谁投资了 A公司”，不把股东当平台。
- 不把基金其他 LP 及他们的投资纳入版图。
- 不把战略合作、框架协议、意向书当已出资。
- 不把间接持股写成直投，不把已退出写成在持。
- 不在兜底模式下声称“平台清单已穷尽”。
