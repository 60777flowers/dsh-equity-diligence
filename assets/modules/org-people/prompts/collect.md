# {{module.name}} · 采集任务：创始人与关键人

## 任务

对 **{{company.name}}**（代码 {{company.code}}）梳理实际控制人、董监高与核心团队。
委托方：{{project.client}}；模块：{{module.name}}；分区：{{unit.partition}}。
产出底稿 `org.people`，只用公开信息，不做投资判断，不写投资建议。

## 输入（已渲染，直接引用，不要改写其结论）

- 主体识别：{{artifact:company.identity}}
- 股权与控制链：{{artifact:ownership.chain}}

## 参数

- 是否检索关键人诉讼：{{params.includeLitigation}}
- 剩余预算：{{budget.remaining}}（超预算先保名单与任期，风险项降级为 `pending_dd`）

## 必答问题（每条落到 `data` 或 `openQuestions`）

1. 实际控制人/控股股东是谁？依据哪份公告的哪一句？与工商口径是否一致？
2. 董事长、总经理、财务负责人、董事会秘书、核心技术负责人分别是谁，任职起始日？
3. 近三年是否有董监高辞职、被免职、被立案、失联或突然更换？
4. 关键人是否有被执行、失信、限高、刑事记录？同名是否已消歧？
5. 是否存在亲属/一致行动人共同任职？来源是否明确表述？
6. 关键人是否在体外公司兼任法定代表人、股东或高管（如 E01 类实体）？

## 检索词起点

- `"<公司全称>" 董事 监事 高级管理人员` / `"<公司全称>" 核心技术人员`
- `"<姓名>" "<公司简称>" 简历` / `"<姓名>" 兼职` / `"<姓名>" 关联企业`
- `"<姓名>" 裁判文书` / `"<姓名>" 被执行人` / `"<姓名>" 失信`
- `"<姓名A>" "<姓名B>" 亲属` / `"<公司全称>" 一致行动`

## 检索路径（按序执行）

1. 最近一期年报"董事、监事、高级管理人员情况"；近三年辞职/聘任公告；
2. 招股说明书或募集说明书的人员章节：简历、任期、兼职、亲属关系披露；
3. 国家企业信用信息公示系统：主要人员、任职企业、股权出质、股权冻结；
4. 中国裁判文书网、中国执行信息公开网（仅限关键人，≤5 人）；
5. 国家知识产权局专利检索：发明人字段（佐证技术角色，不作职务认定）；
6. 权威财经媒体人物报道（只作补充，不作认定）。

## 输出字段清单

- `data.directors[]`：name / role / id / since / note
- `data.keyPeople[]`：同上，"关键"的依据写在 note
- `data.affiliations[]`：person / entity / role / note
- `data.litigation[]`：关键人涉诉摘要（caseId / court / cause / amount / stage / status / date）
- `data.credit[]`：失信、限高、经营异常关联记录

## 输出示例片段（占位符）

```jsonc
{"directors": [{"name": "甲", "role": "董事长", "id": "per_001",
  "since": "2019-03 起，截至 2026-09", "note": "公告口径实控人"}],
 "keyPeople": [{"name": "乙", "role": "核心技术人员", "id": "per_004",
  "since": "2020-07 起", "note": "分管 E01 产品线"}]}
```

## 六态写法

- 查不到：`not_disclosed_after_search` + note（查过哪些库、哪些词、什么日期）；
- 只有部分名单：`lower_bound` + 已知人数；
- 需企业提供文件：`pending_dd` + 需要什么文件；
- 公告与工商冲突：`conflict` + 两个值 + `conflictGroup`；
- 分析型判断（如可替代性）：`estimated` + `derivation`，姓名/职务/任期一律不得 estimated。

## 不要做

- 不查联系方式、身份证号、住址、家庭成员非公开信息、健康与私生活；
- 不重算股权比例、不写控制权结论（那是 `ownership.chain` 的职责）；
- 不把商业库的"疑似关联/疑似亲属"写成事实；
- 不把独立董事、外部顾问算成核心团队；
- 不声称已核验或专家已审。
