# org-people · 审核 rubric（五维 1–5 分）

> 适用：`org.people` 底稿的自动与人工复核。评分只针对本模块产物，不评价公司本身。
> 判定：五维均 ≥3 → 通过；任一维 = 2 → 需修订（退回同单元重跑）；任一维 = 1 → 不通过。
> 本模块状态为 `draft`，rubric 本身也未经专家评审，只作执行一致性检查。

## 1. 事实准确性

| 分 | 判据 |
|---|---|
| 5 | 名单、职务、任期、实控人认定与公告/招股书原文逐字一致；没有一处把"线索"写成"事实"；同名消歧有记录 |
| 3 | 主要人物与任期正确，个别兼职或日期有偏差但已在 note 说明并给出处 |
| 1–2 | 出现人名、职务或任期错误；把商业库"疑似"写成事实；实控人认定与公告冲突却未标 `conflict` |

## 2. 引用准确性

| 分 | 判据 |
|---|---|
| 5 | 每条姓名/职务都有 `evidenceLinks`；quote 为原文片段、locator 精确到章节或页码；不存在"结论有、证据无"的条目 |
| 3 | 主要条目有证据，个别补充信息只挂到聚合页；locator 到章节但不精确到段 |
| 1–2 | 出现无证据的姓名或职务；quote 与实际页面不符；locator 为空或指向搜索页 |

## 3. 完整性

| 分 | 判据 |
|---|---|
| 5 | 董事、监事、高管、核心技术人员四类齐全；实控人认定依据、近三年变动、关键人风险、亲属线索全部回答；缺失项逐条写了原因 |
| 3 | 前两类齐全，核心技术人员或风险项缺 1 项且有 `not_disclosed_after_search` 说明 |
| 1–2 | 只有董事长与总经理两人；或缺失项既不查也不写说明 |

## 4. 来源质量

| 分 | 判据 |
|---|---|
| 5 | 名单类事实公告 + 工商双源；实控人 ≥2 独立来源；无 D 级来源单独支撑事实 |
| 3 | 关键事实 A/B 级单源但可核；D 级来源只用于背景且已标注 |
| 1–2 | 主要结论只靠商业聚合库或自媒体；同一新闻稿的两家转载被当成两个独立源 |

## 5. 对账

| 分 | 判据 |
|---|---|
| 5 | 与 `ownership.chain` 的实控人/一致行动人完全对齐；与 `workforce` 的人数口径不冲突；同一人在 `directors`/`keyPeople`/`affiliations` 的职务一致 |
| 3 | 与上游有 1 处措辞差异但事实一致，已在 note 说明 |
| 1–2 | 实控人姓名或持股主体与上游矛盾且未标 `conflict`；同一人两处职务互相矛盾 |

## 记录要求

- 每条扣分必须写明：维度、条目（人员姓名或字段路径）、扣分理由、需要补的证据；
- 不得用"整体较好""基本准确"等无定位表述；
- 复核人只能提出修订，不得自行把状态改为 `verified`。
