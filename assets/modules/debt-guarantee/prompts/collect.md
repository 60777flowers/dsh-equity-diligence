# {{module.name}} · 采集任务：债务、担保与评级

## 任务

对 **{{company.name}}**（代码 {{company.code}}）梳理有息负债、对外担保、主体/债项评级与表外义务。
委托方：{{project.client}}；模块：{{module.name}}；分区：{{unit.partition}}。
产出底稿 `debt.guarantee`，只用公开信息，不给偿债能力结论。

## 输入

- 财务（负债科目与财务费用）：{{artifact:financials.public}}
- 股权与控制链（股东背景、股权质押）：{{artifact:ownership.chain}}
- 法律风险（软引用，代偿与被执行）：{{artifact:legal.risk}}

## 参数

- 是否检索表外：{{params.includeOffBalance}}
- 剩余预算：{{budget.remaining}}

## 必答问题（每条落到 `data` 或 `openQuestions`）

1. 有息负债总额是多少？由哪些工具构成？各多少？
2. 一年内到期多少？未来 12 个月的集中到期月份？
3. 融资成本是多少？固定还是浮动？有没有财务指标承诺？
4. 对外担保余额多少？被担保方是谁？是否有反担保？是否逾期或代偿？
5. 主体评级与债项评级分别是多少？哪家机构？什么时点？展望如何？
6. 表外有哪些可能转为负债的安排（明股实债、回购承诺、差额补足、保理、未决诉讼）？
7. 是否存在股权质押、应收账款质押、融资租赁登记？

## 检索词起点

- `"<公司全称>" 有息负债` / `"<公司全称>" 短期借款` / `"<公司全称>" 应付债券`
- `"<公司全称>" 对外担保` / `"<公司全称>" 反担保` / `"<公司全称>" 担保余额`
- `"<公司全称>" 评级报告` / `"<公司全称>" 评级展望`
- `"<公司全称>" 明股实债` / `"<公司全称>" 差额补足` / `"<公司全称>" 股权质押`

## 检索路径（按序执行）

1. 年报附注：短期借款、一年内到期的非流动负债、长期借款、应付债券、租赁负债、预计负债、或有事项—对外担保；
2. 中国货币网、中国债券信息网、上海清算所、交易所固收平台：存续债、募集说明书、兑付公告、持有人会议；
3. 评级机构官网：最新跟踪评级报告（机构、等级、时点、展望）；
4. 国家企业信用信息公示系统股权出质登记；中登网应收账款质押与融资租赁登记；
5. 中国执行信息公开网：担保代偿形成的被执行记录；
6. 表外线索：投资协议、公告中的回购/差额补足条款。

## 输出字段清单

- `data.debt[]`：instrument / balance / rate / maturity / note
- `data.guarantees[]`：beneficiary / amount / type / status / note
- `data.ratings[]`：agency / rating / date / outlook
- `data.offBalance[]`：kind / amount / trigger / note

## 口径要求

- 每个余额带"币种 + 单位 + 时点"（如 `CNY 万元 @ 2025-12-31`）；
- 授信额度、注册额度、发行规模、期末余额四者不得混用，加总只用期末余额；
- 担保区分"对合并范围内子公司"与"对外部主体"；区分"担保发生额"与"担保余额"；
- 评级必须写机构 + 等级 + 时点 + 展望，不得只写"评级良好"；
- 有息负债范围写进 `data.debtNote`（是否含租赁负债、带息票据）。

## 六态写法

- 只有"银行借款若干"文字：`not_disclosed_after_search` + 查过的附注与页面；
- 只给授信额度：`lower_bound` + 说明"额度非余额"；
- 需借款合同/担保合同/授信批复：`pending_dd`；
- 年报与债券披露余额不一致：`conflict` + 两组值；
- 综合融资成本等派生值：可 `estimated`，必须带 `derivation`；
- 余额、担保额、评级一律不得 `estimated`，不得用同行均值。

## 不要做

- 不做偿债能力评分、不给违约概率、不判断"是否爆雷"；
- 不把表外承诺直接当已发生负债，也不忽略；
- 不遗漏租赁负债与一年内到期的非流动负债；
- 不用母公司报表代替合并报表；
- 不声称已核验或专家已审。
