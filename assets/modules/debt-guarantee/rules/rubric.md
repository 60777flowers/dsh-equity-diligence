# debt-guarantee · 审核 rubric（五维 1–5 分）

> 适用：`debt.guarantee` 底稿复核。任一维 ≤2 分不通过；本模块为 `draft`。

## 1. 事实准确性

| 分 | 判据 |
|---|---|
| 5 | 负债科目、担保余额、评级等级与时点与年报附注/募集说明书/评级报告一致；余额口径明确 |
| 3 | 主要科目正确，个别工具的分类或期限有偏差但已说明 |
| 1–2 | 把授信额度当余额；把发行规模当余额；评级等级或时点错误 |

## 2. 引用准确性

| 分 | 判据 |
|---|---|
| 5 | 每项负债/担保/评级可追到附注编号、募集说明书页码或评级报告日期；条款为原文引用 |
| 3 | 主要项有证据，个别项只有债券概览页 |
| 1–2 | 余额无出处；评级为媒体转述；表外条款无原文 |

## 3. 完整性

| 分 | 判据 |
|---|---|
| 5 | 余额、期限结构、成本、担保、评级、表外六项齐全；期限结构可看集中到期 |
| 3 | 六项中五项有结论，缺项写了 `not_disclosed_after_search` 与检索记录 |
| 1–2 | 只有一个负债总额；担保与评级完全未查且未说明 |

## 4. 来源质量

| 分 | 判据 |
|---|---|
| 5 | 主数据取年报附注/募集说明书/评级机构原文；登记类取官方平台；媒体仅作线索 |
| 3 | 主数据 A/B 级单源可核；评级取第三方汇总但已回机构页面 |
| 1–2 | 依赖数据库终端或媒体；未打开评级报告原文 |

## 5. 对账

| 分 | 判据 |
|---|---|
| 5 | 有息负债合计与 `financials.public` 负债科目可复算；担保代偿线索与 `legal.risk` 一致；评级期后事项已标注 |
| 3 | 合计数与报表有 <5% 差异且已说明 |
| 1–2 | 合计数与报表矛盾未说明；担保代偿被执行未与 `legal.risk` 对账 |

## 记录要求

- 每条扣分写：维度、字段路径（如 `data.debt[2]`）、理由、需补证据；
- 余额为区间或额度时，扣分只看是否标注，不看数值大小；
- 复核人只能提修订，不得自行改为 `verified`。
