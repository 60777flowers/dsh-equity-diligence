# 未 stable 方向的最低调查清单 · 资质、认定与准入

> 用途：预算不足或只能核到公开公示时的最小集合。不降低证据与六态要求。

## 1. 最低必查

1. **高企状态**：是否在高企认定公示名单内，证书编号与有效期。
2. **专精特新/单项冠军**：是否在工信部或省级公示名单内，批次与有效期。
3. **一项行政许可**：取一个核心许可（生产/注册/经营），记录证号、发证机关、有效期、范围。
4. **一项体系认证**：IATF/ISO/CCC 任一，记录证书号、认证机构、有效期。
5. **主体一致性核对**：证书持证主体 vs 公司全称/曾用名/子公司。

## 2. 最低可交付字段

| 字段 | 最低要求 | 不满足时 |
|---|---|---|
| `data.items[]` | ≥1 行，含 name/issuer/number/validTo/status | 确无 → 1 行 `not_applicable` 占位 + 检索范围 |
| `data.certifications[]` | 可为空，需说明已检索渠道 | 空且无说明 → 门不过 |
| `data.licenses[]` | 可为空，需说明已检索渠道 | 同上 |
| `claims` | ≥2 条，≥1 条 material | 证据不足 → 门不过 |

## 3. 必须标注的缺口

- 有效期原文（只有公示日期时）。
- 许可范围与生产地址原文。
- 子公司持证情况。
- 认证机构的审核报告与不符合项。
- 境外认证（CE/UL/FCC）的公告机构编号与覆盖型号。
- 资质年审/复核记录。

## 4. 禁止的凑数做法

- 用官网证书图片代替官方库核验。
- 把公示期写成已取得。
- 把子公司资质算作母公司。
- 把协会证书当行政许可。
- 用同行资质替代本公司状态。
- 把已过期资质写成有效。

## 5. 交付话术（供交付模块引用）

> 本模块为 draft 方法论，未经金融专家评审。资质与许可状态以官方公示与数据库核验为限，未核验到编号的证书已标 `partial`；有效期截至日已在底稿标注；许可范围以证书原文为准。
